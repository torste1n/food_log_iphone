# Installing it on the iPhone
1. Open https://torste1n.github.io/food_log_iphone/ in Safari. It has to be Safari, not another browser.
2. Tap the Share button, then "Add to Home Screen".
3. Open it from the home-screen icon from then on. The log lives in that installed app, so anything you log in the Safari tab stays separate.
# What to check on the phone
None of this has run on a real iPhone, so these are the things I could not verify:
1. Export: after "Generate", the share sheet should appear with the Excel file. If it downloads to Files instead, that is the fallback and the file is the same.
2. Offline: open the app once with a connection, then try it in flight mode.
3. Keyboard: the amount field should bring up the number pad with a decimal comma.
